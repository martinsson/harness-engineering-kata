## Messages that we want to communicate.
* LLMs are extremely good at code design. Yet, they will predictably produce crap by default.
* What They Do by default is not a good evaluation criteria. The key question is what can we make them do?
* A good harness will consistently produce Good results. or more importantly, defines the minimum quality that will always be produced.
* Honest engineering is to continuously improve the quality of what the agent produce.
* The value of human code review is mainly to improve the harness.
* The harness consists of anything that guides the agent regarding how it works. that includes the agents.md the skills the workflow the referenced documentation and the feedback mechanisms. At all levels.
